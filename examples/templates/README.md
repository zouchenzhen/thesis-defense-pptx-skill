# Template Examples

This directory contains downloadable `.pptx` templates that can be used with
the example workflow.

- `zhengzhou-university-midterm-blank-template.pptx`: a previously used blank
  Zhengzhou University midterm defense template.

Users are responsible for confirming their right to use school templates,
logos, fonts, and other assets. For official submissions, prefer the latest
template published by the relevant school or department.
